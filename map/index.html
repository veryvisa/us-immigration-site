美国身份体系地图

从非移民签证（访问、留学、工作）到绿卡（合法永久居民），再到公民身份。箭头表示常见的研究路径，不代表自动转换或保证获批；每一步的条件都要单独核对。

阶段一

非移民签证

B 访问、F-1 留学（毕业后 OPT）、J-1 交流、H-1B、L-1、O-1 等工作签证。每种签证有自己的停留期与能做的事，先核对当前身份能否工作、能否在境内转换。

从 H-1B 看起 →
阶段二

绿卡（永久居民）

职业移民（EB-1 至 EB-5）、亲属移民、抽签（DV）等类别。大多数类别有年度名额和每国上限，中国大陆出生者单列排期；在美国境内可申请调整身份（I-485），在境外走领馆程序。

看 I-485 调整身份 →
阶段三

入籍

持绿卡满规定年限，满足连续居住、实际居住、品行、英语与公民知识等要求后申请（N-400）。

看入籍条件 →

绿卡：谁来「选」你

进入方式类别怎么进入
雇主担保EB-2、EB-3（通常要劳工证 PERM）、EB-1C雇主先向劳工部申请劳工证、再为你递 I-140；排期到了才能递或批 I-485。看 EB-2 →
自己申请EB-1A 杰出人才、EB-2 国家利益豁免（NIW）不需要雇主和劳工证，自己证明满足标准；仍按类别排期。看 NIW →
家人担保公民的配偶、父母（IR／CR）与 F1–F4 优先类别美国公民或绿卡持有人为亲属递 I-130；优先类别按排期。看亲属优先类别 →
投资EB-5，以及「金卡」按法定投资额与创造就业等条件申请；金卡的法律性质与受理状态看其页面的官方原文。看 EB-5 →
抽签DV 多元化移民；H-1B 名额抽签（非移民）先登记、被选中才能递交；是否有资格参加看国籍与出生地。看 DV 抽签 →

常见研究路径

F-1 → OPT／STEM OPT → H-1B → 雇主 PERM 与 I-140 → I-485

每一步都要重新满足条件；H-1B 有年度名额抽签，2025–2026 年又有付款与选中方式的变化，见政策动态。

核 OPT →
H-1B 或 O-1 → EB-1A／NIW 自申

不依赖雇主劳工证，但中国大陆出生者仍按 EB-1 或 EB-2 中国大陆一栏排期。

核 EB-1A →
公民配偶：I-130 → CR-1／IR-1 → 条件绿卡转正 → 入籍

结婚未满两年拿到的是条件绿卡，需按期申请移除条件；入籍年限对公民配偶另有规定。

核公民配偶 →
EB-5 投资 → 条件绿卡 → 移除条件

投资额、就业岗位与区域中心项目的授权期限照官方原文核对；中国大陆出生者非预留类别有排期。

核 EB-5 →
